# LiteLLM Proxy Sample

LiteLLMを使用して複数のAIモデルを統一APIで利用するためのサンプルプロジェクト。

## クイックスタート

1. 環境セットアップ

   ```bash
   mise run setup
   ```

2. プロキシサーバー起動

   ```bash
   mise run run
   ```

3. API テスト
   ```bash
   bash ./src/chat.sh
   ```

## 主な機能

- 複数のAIモデルへの統一APIアクセス
- シンプルなcurlベースのテスト環境
- mise による開発環境管理

詳細な技術情報や開発手順については、プロジェクトのメモリファイルを参照してください。
